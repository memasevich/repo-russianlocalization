# R.E.P.O. Russian Localization

Полная русская локализация игры **R.E.P.O.** (Semiwork). 
Переведено ~100% игрового контента: предметы, монстры, обучение и интерфейс.

## 📥 Установка

Перевод работает через официальный механизм игры, поэтому **дополнительные моды (BepInEx и др.) НЕ НУЖНЫ**.

1.  Зайдите в папку `translation` этого репозитория.
2.  Скачайте три файла:
    *   `Game.tsv`
    *   `HUD.tsv`
    *   `Menu.tsv`
3.  Перейдите в папку с установленной игрой (в Steam):
    `...\steamapps\common\REPO\REPO_Data\StreamingAssets\Localizations\`
4.  Вставьте скачанные файлы прямо в папку `Localizations` (с заменой, если потребуется).
    *   *Примечание: кладите файлы именно в корень папки Localizations, а не в Default!*
5.  Запустите игру. Она автоматически станет на русском языке.

# R.E.P.O. Русификатор (100%) by memasevich

Полная качественная локализация игры **R.E.P.O.** (Semiwork). 
Переведено ~100% игрового контента: все предметы, монстры, подробное обучение и интерфейс настроек. 

## 📥 Установка

Перевод работает через официальный механизм игры, поэтому **дополнительные моды (BepInEx и др.) НЕ НУЖНЫ**.

### Шаг 1: Скачивание
1. Нажмите на зеленую кнопку **"<> Code"** в правой верхней части этой страницы.
2. Выберите **"Download ZIP"**.
3. Распакуйте скачанный архив. Вам понадобится папка `Русификатор by memasevich`.

### Шаг 2: Перенос файлов
1. Зайдите в папку `Русификатор by memasevich` в распакованном архиве.
2. Скопируйте из неё три файла: `Game.tsv`, `HUD.tsv` и `Menu.tsv`.
3. Перейдите в папку с установленной игрой (в Steam):
   `[Папка Steam]\steamapps\common\REPO\REPO_Data\StreamingAssets\Localizations\`
4. Вставьте скопированные файлы прямо в папку **Localizations** (с заменой, если потребуется).
   * **ВАЖНО:** кладите файлы именно в корень папки `Localizations`, а не во внутреннюю папку `Default`!

### Шаг 3: Запуск
Просто запустите игру. Она автоматически подхватит перевод, и всё будет на русском языке.

# R.E.P.O. Russian Localization

Проект полной русской локализации игры **R.E.P.O.** (Semiwork). 
Переведено ~100% игрового контента, включая предметы, врагов, обучение и интерфейс.

## 📥 Установка

Для работы перевода не требуются дополнительные моды (BepInEx и т.д.). Игра поддерживает внешнюю локализацию "из коробки".

1.  Скачайте архив с переводом или клонируйте репозиторий.
2.  Скопируйте файлы из папки `translation` репозитория:
    *   `Game.tsv`
    *   `HUD.tsv`
    *   `Menu.tsv`
3.  Перейдите в папку с установленной игрой:
    `[Папка Steam]\steamapps\common\REPO\REPO_Data\StreamingAssets\Localizations\`
4.  Вставьте скопированные файлы прямо в папку `Localizations` (не в `Default`!).
5.  Запустите игру. Она автоматически подхватит русские файлы.

## 🛠 Для разработчиков (Автоматизация)

Проект построен по системе, аналогичной локализации *Caves of Qud*, с централизованным словарем и скриптами автоматизации.

*   `dictionaries/dictionary.json` — основной файл со всеми переводами (Ключ: Значение). Править нужно именно его.
*   `scripts/build.py` — собирает финальные `.tsv` файлы из словаря.
*   `scripts/sync_new_strings.py` — проверяет файлы игры на наличие новых английских строк после обновлений и добавляет их в словарь.
*   `scripts/export_to_helprus.py` — выгружает все тексты в удобный `.txt` файл на рабочий стол для быстрой проверки.

### Как обновить перевод после патча игры:
1. Запустить `python scripts/sync_new_strings.py`.
2. Перевести появившиеся английские строки в `dictionary.json`.
3. Запустить `python scripts/build.py`.
4. Скопировать новые файлы из `translation` в папку игры.

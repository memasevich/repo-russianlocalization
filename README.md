# R.E.P.O. Русификатор (100%) by memasevich

Полная качественная локализация игры **R.E.P.O.** (Semiwork). 
Переведено ~100% игрового контента: все предметы, монстры, подробное обучение и интерфейс настроек. 

## 📥 Как скачать и установить

### Шаг 1: Скачивание
1. Нажмите на зеленую кнопку **"<> Code"** в правой верхней части этой страницы.
2. Выберите **"Download ZIP"**.
3. Распакуйте скачанный архив. Вам понадобится папка `Русификатор by memasevich`.

### Шаг 2: Как найти папку с игрой (самый быстрый способ)
Если вы не знаете, где установлена игра, сделайте следующее:
1. Откройте **Steam** и перейдите в свою **Библиотеку**.
2. Найдите в списке игру **R.E.P.O.** и нажмите на неё правой кнопкой мыши.
3. Выберите **Управление** (Manage) -> **Просмотреть локальные файлы** (Browse local files).
4. Откроется папка игры. Теперь перейдите по пути:
   `REPO_Data` -> `StreamingAssets` -> `Localizations`

### Шаг 3: Установка перевода
1. Зайдите в папку `Русификатор by memasevich` в распакованном архиве (который вы скачали в Шаге 1).
2. Скопируйте из неё три файла: `Game.tsv`, `HUD.tsv` и `Menu.tsv`.
3. Вставьте их в открытую папку **Localizations** (в папке игры).
4. Система спросит: "Заменить файлы в папке назначения?". Нажмите **Да (Заменить)**.
   * **ВАЖНО:** кладите файлы именно в корень папки `Localizations`, а не во внутреннюю папку `Default`!

### Шаг 4: Запуск
Просто запустите игру. Она автоматически подхватит перевод, и всё будет на русском языке.
